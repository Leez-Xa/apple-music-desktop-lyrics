# Apple Music 桌面歌词

Windows 上的 Apple Music 桌面歌词工具。播放歌曲时从 [LRCLIB](https://lrclib.net/) 匹配同步歌词（同桌面展开歌词面板时还可自动只读融合 Apple Music 官方翻译），在桌面透明置顶显示；也可导入本地歌词。

## 快速开始

1. 确保已安装 Windows 版 Apple Music 和 .NET Framework 4.8。
2. 获取本仓库的源码，在项目目录双击 `Start.cmd`。首次运行时会在 `outputs/` 下构建。
3. 手动启动后歌词浮层会直接显示。播放歌曲后自动匹配歌词；若手动隐藏了浮层，可用 `Ctrl+Alt+L` 或托盘菜单恢复。将鼠标移入歌词浮层可打开设置。
4. 可选启用随 Apple Music 自动待命与启停：运行 `.\scripts\StartStandby.ps1`，或通过 `.\scripts\ManageStandby.ps1 -Action Status / PreviewInstall / Install` 管理开机待命。

## 功能

- **透明置顶两/三轨歌词**：默认显示当前句与下一句；可在「设置 → 歌词」开启「显示翻译」「显示音译」动态切换双轨或紧凑三轨，超长歌词保持字号横向平滑滚动。
- **拖动、贴顶与穿透锁定**：解锁时支持拖动、贴顶与左右调整宽度；锁定时主浮层真正鼠标穿透，悬停外侧可点「解锁」，也可通过托盘菜单或 `Ctrl+Alt+Shift+L` 解锁。
- **自定义调色盘与外观记忆**：内置 WPF 调色盘，支持字体色/描边色分别选色、HEX/RGB 联动、16 格自定义颜色持久化（打开默认选中首个空槽、支持自主点选带黑框高亮与清除），并跨重启记住位置、字号、字体和逐曲校时。
- **本地备用与纯文本**：支持导入本地 UTF-8 LRC/TXT；无时间戳文本仅预览前两行，不假装同步。

## 隐私与限制

歌词匹配会将歌名、歌手、专辑和时长发送到 LRCLIB，不发送音频、账号或令牌。本工具独立于 Apple Music 运行，不修改客户端配置，也没有客户端内置开关；跨虚拟桌面隐藏 Apple Music 时暂无法直读其 XAML 歌词子树。
