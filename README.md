# Apple Music 桌面歌词

双击 Start.cmd 启动。Apple Music 播放歌曲后，工具自动从 LRCLIB 匹配真实同步歌词，并按实际进度显示与滚动换行，无需导入文件。本地歌词仅作为备用。

- [完整使用与构建说明](docs/README.md)
- [检测记录与已知限制](docs/VALIDATION.md)

不需要安装依赖，不改变 Apple Music 配置。经用户授权，仅向 LRCLIB 发送歌名、歌手、专辑和时长用于匹配歌词；不发送音频、账号或令牌。
