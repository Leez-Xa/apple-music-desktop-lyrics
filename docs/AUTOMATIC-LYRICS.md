# 自动真实歌词交付记录

日期：2026-11-06，Asia/Shanghai。此记录为当前版本验收标准，替代早期“只有本地导入”和“验证标记通过即完成”的判断。

## 当前行为

Apple Music 播放后，自动读取媒体信息，向获授权的 LRCLIB 查询匹配歌词，解析真实 LRC，并按 Apple Music 实际时间轴显示当前句与下一句、滚动换行。换歌取消旧查询并自动获取新歌。正常使用不需要手动导入。

提供器先接受用户主动选择的本地备用覆盖，再使用 LRCLIB。LRCLIB 请求仅为 HTTPS GET，不携带账户、令牌或 Cookie，不上传音频或发布歌词。禁止自动重定向到其他主机；仅发送获授权的歌曲名称、艺人、专辑和时长。成功与未匹配缓存只在本进程内存中保存。

针对本机 Apple Music 的“歌手 — 专辑”合并字段，查询前分离歌手和专辑。华语歌支持简繁体与英文别名处理；严格筛掉歌名或艺人不符及相差超过 3 秒的版本。优先同步歌词，纯文本仍明确标为非同步。网络失败有限次自动重试，遵守 Retry-After 并增加等待抖动；“重试”可清除未匹配缓存。
