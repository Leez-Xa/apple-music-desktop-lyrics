## 已知限制与后续方案

| 限制 / 待验证项 | 当前行为与后续方案 |
| --- | --- |
| 不能自动获取内置歌词 | 当前窗口提示导入本地 LRC；继续只读探测歌词面板，只有确认文本与同步信息后才新增原生提供器 |
| 外部歌词服务未接入 | 保留 ILyricsProvider 与顺序回退组合器；服务商、联网和数据发送范围须单独明确授权 |
| 真实暂停、跳转与切歌仍待验证 | 正常播放的媒体到窗口链路现已实测通过；暂停、跳转和切歌仍以逻辑检查为证据，本轮未主动控制 Apple Music，也未在观测区间内遇到自然切歌 |
| 拖动、Tab 流程、托盘双击和全局快捷键需人工复核 | 已实现相应事件与键位；本次自动验证覆盖窗口隐藏及再次启动恢复，未宣称完成所有真实键鼠操作验证 |
| DPI、多显示器与高对比主题待测 | 使用 WPF DIP 与布局舍入；当前只在本机默认环境验证，尚未覆盖跨显示器拖动和不同缩放 |
| 导入关联不跨重启保存 | 文件只读，按当前歌曲在内存关联；后续如需持久化，可将配置限定在项目内单独实现 |
| 相同媒体元数据的不同录音 | 系统未提供稳定曲目 ID 时，来源、标题、艺人与专辑全部相同的录音不能区分；需选用正确版本歌词 |
| 曲目 ID、专辑等字段可能缺失 | 使用现有元数据关联键；不从其他应用或远程服务猜测缺失信息 |

没有下载或安装组件，没有配置外部服务，没有修改 Apple Music、系统设置或用户级配置。检查只操作本次启动的歌词程序；应用运行时的托盘与快捷键在退出时释放。
