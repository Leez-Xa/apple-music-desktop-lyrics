# Apple Music Desktop Lyrics

## Register
Product: Windows desktop utility.

## Purpose
Display a readable, always-on-top, line-synchronized lyric window driven by Apple Music for Windows. Prefer accessible Apple Music lyrics and fall back to synchronized external lyrics. Launch through a single entry; no separate control application.

## Users and principles
For an Apple Music listener who keeps another application in the foreground. Keep lyrics legible, controls quiet, keyboard access available, and missing lyrics or disconnected playback explicit. Preserve Apple Music installation and user configuration. Native in-client integration is gated by runtime evidence.
